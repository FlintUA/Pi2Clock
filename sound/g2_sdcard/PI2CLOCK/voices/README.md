# Pi2Clock G2 voice packs

These folders contain no audio yet. After recording or synthesising the files and validating a pack, set `installed` in its `voice.json` and list it in `../manifest.json`.

Each of the twelve packs (ru-RU and de-DE, three female and three male voices each) is self-contained; never mix voices within one phrase. Texts: [doc/generations/g2/VOICE.md](../../../../doc/generations/g2/VOICE.md) and `voice_phrases_ru_de.csv`.
