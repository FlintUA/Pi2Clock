# Pi2Clock G1 1.1.0

Release `g1-v1.1.0`, 2026-11-23. The first release with a generation tag and the first since [v1.0.0](v1.0.0.md). The clock can now be controlled from a phone or tablet browser, updated over the air, and plays music on Bluetooth speakers without crackling.

## New since 1.0.0

**Browser control**
- A page served by the clock in one vertical column: clock window, timer and alarms, music, quick actions (sound, speaker, speech) and settings pages. English, Russian, German; light, dark or automatic appearance.
- Home mode through the home Wi-Fi (two saved networks, Main and Backup, with failover) or Direct mode through the clock's own access point `SpeakingClock`; switching from the clock or the page.
- Browser pairing with a six-digit code on the LCD, up to four remembered browsers, optional home trust, permission list with Forget.
- Settings from the page: volumes and outputs, announcements and quiet hours, display light, timer completion, birthdays, date and time with NTP, Bluetooth speakers, Wi-Fi networks (search, test and save, connect).

**Updates**
- A/B over-the-air updates from the browser with a trial boot, automatic rollback and return to the same network mode. A connected Bluetooth speaker is disconnected for the upload and reconnected afterwards.

**Timer, alarms, birthdays**
- Countdown up to 23:59:59 with a precise hours/minutes/seconds editor and quick presets in the browser.
- Timer completion options: spoken message on/off, signal, fixed or random music, none; optional beeps in the last five seconds; Stop timer sound.
- Alarms with random music; Stop, Snooze and Cancel snoozed repeats from the browser.
- Fifteen annual birthdays (was five), with an optional birth year.

**Audio**
- Bluetooth music is paused for hourly speech and alarms and resumes at the same position.
- Play/Pause buttons on the speaker control the clock's music player.
- Stable Bluetooth audio: Wi-Fi power saving off while streaming, automatic SBC bitpool (at least seven frames per packet), checked send results, recovery of up to 300 ms after a radio stall, larger audio buffer. Tested on JBL Link Portable (25 minutes without crackling), PRO X 2, Google Nest Audio and SSTB 10.
- LCD shows `MUTE` and the active output (`BT`/`SPK`) on the clock screen.

## Installing

**From the browser (clock already running a G1 A/B build):** Settings → System → Firmware update, choose `Pi2Clock-G1-v1.1.0-ota29.clockota` from the release assets, Upload, then Install. The clock restarts into the new image, checks it and keeps it; settings are preserved.

**Over USB (first installation):** check out the tag, build and install as described in the [README](../../README.md#building-and-installing-windows); keep `speaking_clock_c.build-id.txt` next to the UF2.

**SD cards:** both cards need the same numbered folders from [sound/_sdcard](../../sound/_sdcard/). For the five-second timer warning copy the new `19/001.mp3` to both cards. Music for Bluetooth must be present in folder 08 of the Pico's SPI card.

## Compatibility

- Settings are stored in Flash format v18 and every earlier format is read. Version 1.0.0 reads only up to v11: after saving with 1.1.0 a downgrade to 1.0.0 loads older settings or defaults. See [settings compatibility and rollback](../NETWORK_TIME.md#settings-compatibility-and-rollback).
- OTA packages are G1-specific (target `0x23500002`, `g1-` build IDs); the OTA sequence of this release is 29.

## Known limitations

- German recordings for the timer-completion message and the alarm-slot numbers are missing; spoken years cover 2023–2029.
- The local half-hour and warning beeps are quiet on the DFPlayer; the occasional double Bluetooth sound is not yet explained.
- A radio stall longer than the speaker's own buffer can still cause a short crackle.
- Open acceptance checks are listed in [feature status](../FEATURE_STATUS.md).
