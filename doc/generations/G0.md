# G0 — original MicroPython clock (archived)

G0 covers every MicroPython firmware of the clock, from the first single-file program to v3.10.0. It is archived: the code in [generations/g0-micropython](../../generations/g0-micropython/) is kept for reference and is not maintained. The assembled clock was migrated to [G1](G1.md) in November 2026; the migration is recorded in [doc/history](../history/).

## Hardware

| Part | Connection |
| --- | --- |
| Raspberry Pi Pico (RP2040); v3.10.0 ran on a Pico 2 W | — |
| LCD1602 with PCF8574 I2C backpack | I2C0: SDA GP0, SCL GP1 |
| DS1302 RTC | CLK GP2, DIO GP5, CE GP4 |
| DFPlayer Mini with microSD card and speaker | UART0: Pico TX GP16 → DFPlayer RX, Pico RX GP17 ← DFPlayer TX; BUSY GP18 |
| Volume encoder | DT GP14, CLK GP15, button GP20 |
| Timer encoder | DT GP11, CLK GP10, button GP19 |
| Buttons | GP28, GP21, GP22, GP26, GP27 to ground (internal pull-ups) |

The original description used 1 kΩ pull-up resistors on the encoders. The [original schematic](../../generations/g0-micropython/schematic/shematic.png) shows this wiring; it does not include the G1 SPI card, the relocated timer encoder or the LCD light output.

## Firmware versions

| Version | Source | Notes |
| --- | --- | --- |
| 1.x (last 1.16) | `source/speaking_timer_clock.py` | Single file. Timer in whole minutes (up to 240), five fixed time points, hourly speech, half-hour signal, old-clock chime, quiet mode 22:00–07:00, settings only in source code. [Version notes](../../generations/g0-micropython/doc/version.txt) |
| 2 (single file) | `source/speaking_timer_clock_v2.py` | Reworked single-file version. [Test plan](../../generations/g0-micropython/doc/V2_TESTING.md) |
| 2.0.0 modular | `source/v2-modular/` | August 2026 rewrite: package `speaking_clock` (async core, hardware abstraction, priority speech queue, JSON settings, locales). Kept from a local working copy; it was never committed before the 2026-11-20 archive and did not replace v3. [State notes](../../generations/g0-micropython/doc/PROJECT_STATE_2026-08-26.md) |
| 3.x (last 3.10.0) | `source/v3/` | Modular MicroPython used on the assembled clock until the C migration: five daily alarms, music player, Wi-Fi/NTP and RTC drift calibration on Pico 2 W. [Bring-up](../../generations/g0-micropython/doc/V3_BRINGUP.md), [controls](../../generations/g0-micropython/doc/MICROPYTHON_CONTROLS_AND_MODES.md), [roadmap](../../generations/g0-micropython/doc/MICROPYTHON_V3_ROADMAP.md) |

`generations/g0-micropython/library/` holds the third-party MicroPython drivers (LCD, DS1302, DFPlayer, rotary encoder, picozero). `tools/` holds the August 2026 SD-card migration and phrase-generation scripts. `sound-drafts/` holds a regenerated variant of German phrase 17/015 from 2026-08-27 that was never used on the clock.

## Audio

G0 established the numbered folder layout that G1 still uses on both cards (see [G1 audio assets](G1.md#audio-assets)). There was one sound path: the DFPlayer played files from its own card on command over UART.

## Transition to G1

Bluetooth speaker output was first proven as a C / BTstack A2DP source experiment on a spare Pico 2 W ([experiments/bluetooth_a2dp_nest](../../experiments/bluetooth_a2dp_nest/)). The clock firmware was then ported module by module from MicroPython v3.10.0 to C, with v3.10.0 as the behavioral reference. The port, its module mapping and the verification gates are recorded in the [migration plan](../history/C_MIGRATION_PLAN.md) and the [2026-11-06 audit](../history/C_MIGRATION_AUDIT_2026-11-06.md). G1 kept the G0 panel wiring except for the timer encoder, which moved to GP12/GP13 to free SPI1 for the second card.
