# Pi2Clock G2 - полный комплект документации

Дата сборки архива: 2026-11-23.

## Основные документы

- `docs/Pi2Clock_G2_WIRING_AND_ASSEMBLY.md` - модули, GPIO/пины, питание, пайка и проверки.
- `docs/Pi2Clock_G2_SD_LAYOUT.md` - структура microSD и правила офлайн/онлайн данных.
- `docs/Pi2Clock_G2_VOICE_PHRASES_RU_DE.md` - тексты и система русских/немецких речевых сообщений.
- `docs/Pi2Clock_G2_VOICE_PHRASES_RU_DE.csv` - таблица речевых фраз для TTS/записи.
- `sd/Pi2Clock_G2_SD_STARTER.zip` - готовый пустой каркас SD-карты, включая JSON-шаблоны; распаковать отдельно.

## Справочные материалы

- `references/original_connections/` - предоставленные пользователем CSV/CIR со старой разводкой. Это НЕ готовая схема G2.
- `references/early_V4_concepts/` - ранние документы по UI и аудио, сохраняются для истории. При расхождениях ориентироваться на G2 документы.

## Важно

Это проектная документация, НЕ аппаратно проверенная схема. До окончательной пайки сверить пины и питание фактических плат; провести тестирование узлов по отдельности. Устройство G1 использует иной формат звука, новая SD-структура не подходит к G1 без реализации поддержки в прошивке G2. Внутри `SD_STARTER.zip` нет аудиозаписей.
