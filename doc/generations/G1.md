# G1 — Pico 2 W C firmware with DFPlayer (current)

G1 is the assembled clock and the generation under active development. The firmware identifies itself as **Pi2Clock G1**; build IDs start with `g1-`, OTA packages use target `0x23500002`. Development happens on `main` (after the 2026-11-20 consolidation; previously `codex/phone-control`). Releases are tagged `g1-vX.Y.Z`; until the first such tag, `v1.0.0` is the version baseline.

## Hardware

| Part | Notes |
| --- | --- |
| Raspberry Pi Pico 2 W | RP2350 (Arm Cortex-M33, 520 KB SRAM, 4 MB Flash), CYW43439 Wi-Fi + Bluetooth Classic |
| LCD1602 with PCF8574 I2C backpack | Address detected automatically (0x20–0x27, 0x38–0x3F) |
| External LCD light | LED driven from GP6 PWM through a transistor/MOSFET stage with a current-limiting resistor |
| DS1302 RTC | Bit-banged, Europe/Berlin local time; corrected from NTP when available |
| DFPlayer Mini | Local sound: plays MP3 files from **card A** to its own speaker output |
| microSD module on SPI1, 3.3 V | **Card B**: read-only FAT32 copy of the same numbered folders, used for Bluetooth audio |
| Two rotary encoders with push buttons | Volume (sound on/off) and timer (start/cancel, menu navigation) |
| Five push buttons | Alarm, Mode, Minus, Settings/Plus, Timer-mode; to ground with internal pull-ups |
| Bluetooth speaker (optional) | Classic A2DP sink with SBC and SSP pairing; up to four remembered |

The pin assignment is defined in [the Pico 2 W pin map](../HARDWARE_PICO2W.md), which is authoritative. Bus summary: I2C0 GP0/GP1 (LCD), GP2/GP4/GP5 (RTC), GP6 (light PWM), SPI1 GP8–GP11 (card B), GP12/GP13 and GP14/GP15 (encoders), UART0 GP16/GP17 + BUSY GP18 (DFPlayer), GP19–GP22, GP26–GP28 (buttons). A complete power schematic of the installed modules is still open (see [roadmap](../ROADMAP.md)).

Differences from G0: card B on SPI1 added, the timer encoder moved from GP10/GP11 to GP12/GP13, LCD light output on GP6 added, Pico 2 W required.

## Audio paths

1. **Local (SPK):** the firmware sends DFPlayer commands over UART0 at 9600 baud and watches BUSY; the DFPlayer decodes from card A.
2. **Bluetooth (BT):** the Pico reads the same file from card B, decodes it with the Helix MP3 decoder into a PCM ring buffer, encodes SBC and streams through the BTstack A2DP source. If the speaker or the file is unavailable, the clock falls back to the local path.

Four independent output preferences choose SPK or BT for manual speech and music, hourly speech, timer and alarms. LOCAL and BT volumes (0–30) are stored separately. Both cards must hold identical numbered folders.

## Firmware

C11 on Pico SDK 2.3.1, built with CMake and Ninja. Main components in [firmware/pico2w_c](../../firmware/pico2w_c/):

| Area | Modules |
| --- | --- |
| Application logic (pure, host-tested) | `app/`: countdown and timer editor, timer warning, alarm engine with weekday masks and snooze, birthdays, music playlist/sleep/catalog/retry, civil time and DST |
| Audio | `audio/`: DFPlayer command queue, speech planner, output router, PCM ring buffer, MP3 decoding (Helix) |
| Drivers | `drivers/`: LCD1602, DS1302, DFPlayer, encoders/buttons, SD over SPI, read-only FAT32 |
| Services | `services/`: Flash settings, Bluetooth device catalog, Wi-Fi/NTP, phone web server and access control, Wi-Fi profiles and scan, OTA image/boot/upload |
| Integration | `main.c`: main loop, LCD screens and menus, USB serial commands, Bluetooth/Wi-Fi glue |
| A2DP source | Generated at configure time from the SDK's `a2dp_source_demo.c` by [experiments/bluetooth_a2dp_nest](../../experiments/bluetooth_a2dp_nest/) |

Build options (see [build-clock-bt.ps1](../../build-clock-bt.ps1)): Bluetooth A2DP is always on for the clock build; `-Mp3` enables card B and Helix; Wi-Fi/NTP is on unless `-NoWifi`; `-PhoneWeb` adds browser control; `-OtaAb -OtaSequence N [-OtaTrial]` builds an A/B image for browser updates.

### Persistent storage

| Flash area | Use |
| --- | --- |
| Application image | Single image, or OTA slots A and B (1536 KiB each, starting at 4 KiB and 1540 KiB) |
| Sectors −6 and −5 | Clock settings, A/B records with CRC and sequence numbers; current record format v18, all older formats readable; loading never writes |
| Sector −4 | Legacy settings slot, read-only for migration |
| Sectors −3 and −2 | BTstack pairing keys (not touched by the clock) |
| Sector −1 | Reserved (RP2350-E10 UF2 workaround) |

### Network and browser control

- **Home:** joins one of two saved networks (Main first, then Backup), WPA2-PSK or open. NTP from `pool.ntp.org`, hourly resynchronization, Europe/Berlin CET/CEST.
- **Direct:** the clock's own access point `SpeakingClock` at `192.168.4.1`; no router or internet needed.
- **Browser page** served by the clock: status, timer, player, alarms, birthdays, sound/display/announcement settings, Bluetooth, Wi-Fi, browser permissions, date/time and firmware update. Pairing uses a one-time code shown on the LCD; up to four browser permissions are remembered. See [web control](../WEB_CONTROL_SPEC.md) and the [redesign specification](../WEB_UI_REDESIGN_SPEC.md).
- **OTA:** authenticated upload of a `.clockota` package into the inactive slot, verification, trial boot and acceptance; see [OTA web update](../OTA_WEB_UPDATE.md).

## Capacity

One countdown (1 s – 23:59:59), five alarms, fifteen annual birthdays, music tracks 1–255, four saved Bluetooth speakers, two home Wi-Fi profiles, four browser permissions, four simultaneous browser clients.
